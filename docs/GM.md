# 《断链》管理后台（GM）

入口：<https://lianyingxue37-coder.github.io/yingxuelian/admin/>（不在游戏里显示链接，`noindex`）。

## 登录与权限

- 用**游戏账号**登录（账号名或绑定的邮箱 + 密码）。只有 `duanlian_private.gm_admins` 名单里的账号能进，其他账号登录后会被拒绝并退出。
- 两种身份：**站长**（owner）能增删管理员、能操作其他管理员的账号；**管理员**（admin）能管理玩家、商品、公告，不能动管理员名单和其他管理员。
- 首个站长：迁移时从旧名单 `duanlian_private.admin_members` 自动带入（生产库里是 `yinglian`）。也可以在 SQL Editor 手动加：

  ```sql
  insert into duanlian_private.gm_admins (uid, role)
  select id, 'owner' from public.profiles where username = '<游戏账号名>'
  on conflict (uid) do update set role = excluded.role;
  ```

## 功能

| 页面 | 能做什么 |
| --- | --- |
| 总览 | 注册 / 新增 / 活跃 / 封禁人数，24 小时对局与联机，开着的房间、匹配人数，近 14 天注册和对局趋势，最近操作 |
| 玩家 | 按账号名、昵称、UUID 搜索，按注册 / 登录 / 段位 / 对局排序；点开看详情 |
| 玩家详情 | 改昵称、头像、佩戴称号、段位分；**发放 / 回收物品**；**给予 / 回收成就**；封号（1 小时～永久，封号立即踢下线）、解封、踢下线、清空战绩；看最近 30 场对局和针对这个号的操作记录 |
| 商品 | 新建 / 编辑商品（称号、组合包），改断链币价格、上下架、排序；**批量发放**（贴一串账号名，一次最多 500 个） |
| 对局 | 开着的房间、最近联机对局及核验状态 |
| 公告 | 发布公告（普通 / 重要，可设显示时长），下线 / 重新上线。玩家在游戏标题页看到，每条只弹一次 |
| 操作日志 | 所有后台操作：谁、什么时候、对谁、做了什么、原因、改动前后 |
| 管理员 | 查看名单；站长可以添加 / 移除管理员 |

所有改动都要填**原因**，记入操作日志，不能删除。

## 说明与限制

- 回收物品会同时摘掉玩家正在佩戴的该称号。回收玩家花钱买的物品时，后台会醒目提示。
- 封号后玩家已拿到的访问令牌最多还能用约 1 小时（Supabase 令牌有效期），但不能续期、不能重新登录；联机匹配队列会立即移除。
- 断链币余额在支付宝 / 一人付那边记账，后台不能直接加减断链币；需要补偿时直接发放物品。
- 世界聊天（生产库里 Codex 建的 `world_chat`）还没有接入后台。
